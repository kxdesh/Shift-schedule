ГРАФИК СМЕННОСТИ — PWA

Состав:
- index.html — приложение
- manifest.json — параметры PWA
- sw.js — офлайн-кэш
- icons/ — иконки

Важно:
PWA нельзя нормально установить на iPhone из file://. Нужен HTTPS-сайт.
Бесплатный вариант: разместить эту папку на GitHub Pages или другом бесплатном HTTPS-хостинге.

После публикации:
1. Откройте сайт в Safari на iPhone.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Запустите «График» с иконки.

Данные приложения хранятся в localStorage браузера. Внутри приложения уже есть «Экспорт» и «Импорт», поэтому рекомендуется периодически делать резервную копию JSON.
